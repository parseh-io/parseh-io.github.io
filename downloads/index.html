Downloads

Every released version of Parseh, the newest first. How to install one is in the guide.

Parseh is installed on a computer, not on a phone or a tablet: open parseh.io on the computer and download it there. Once it runs, this device can use it through the browser.

    The list is read from GitHub when this page opens. If it does not appear, every version is on Parseh's releases page on GitHub.
